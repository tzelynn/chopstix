# markdown sticky notes

add a new type of sticky note that uses markdown to format the note. this allows chopstix to double up as a notetaking app as well. one possible use case will be to have it on the side while i am reading an article so that it's easier for me to take notes and shift the sticky note around as i am taking notes.

## markdown note requirements
- the typing will be in markdown format, with instant renders on the fly
- the markdown should be able to exist as a sticky note or also in full screen, and should come with a save button (in full screen) to a .md file in a location that the user specifies, or as a pdf
- feel free to reference other note taking apps like notion for some lightweight quality of life features that should be included in this markdown functionality

## concerns
- now that this will be both a sticky notes app and a note taking app, the storage of these should be efficient and reliable.
- the overall chopsticks noodle theme should continue on as far as possible
- the design should still remain clean even with expanded set of capabilities.
