# chopstix

cute, simple sticky note app for mac

## features

- create sticky notes that exist on the screen
- sticky notes can have customisable designs
- text have different styles like bold, italics etc
- have checklist and bullet point formats
- have an overall board in the app with all sticky notes
- sticky notes can exist purely in the app or stuck around the screen
- size of note can be adjusted by dragging the corner
- placement of note can be adjusted by dragging the top edge 

## theme

- each sticky note on the screen should be held up by a pair of chopsticks
- the different customisable sticky note designs should be noodle-themed, where each colour represents a different type of asian noodle
    - the background or corners of the sticky note can have some cute and simple illustration to go with the noodle, eg prawn noodle can have small cute prawns around the corner of the note
- the overall app board would be a menu style

## design principles

- simple and not too tacky yet in theme
- generally lighter colour palette that goes well together
